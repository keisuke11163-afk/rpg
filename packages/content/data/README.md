# data

コンテンツのデータ（JSON）を、種類ごとのフォルダに置く（開発計画書 6.2）。
データの形（スキーマ）と検証は U-02 `feature/data-foundation` で作る。

| フォルダ | 中身 |
|---|---|
| `tags/` | 星紋タグ（仕様書 1.5） |
| `stats/` | 能力値 |
| `effects/` | 効果（職技の一定時間の効果など） |
| `ailments/` | 状態異常・崩し |
| `skills/` | 技（全ジョブ共通の通常攻撃と、ジョブごとの技） |
| `gauges/` | 職能ゲージ（闘志など） |
| `jobs/` | ジョブ（適性・技を覚えるジョブLv） |
