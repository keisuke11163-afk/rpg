## 終わった単位
- HUD-1 HUD：左下にHP・MP・気力・職能ゲージの棒、下中央に技の枠6つと薬瓶、効果の札、ボスの棒、小さな地図、Lv・ジョブの表示。中身は `src/ui/hud-model.ts`（Phaser に依存しない。テストあり）、描画は `src/ui/Hud.ts`
- HUD-2 詳しい情報の切り替え：開発用の文字を設定の「詳しい情報」で出し入れ（初期は出さない）
- HUD-3 手応え：被弾の赤い縁と揺れ・HPが少ないときの縁の脈動・Lv UP の表示・会心/崩しの小さな揺れ・当てた敵の白い光
- HUD-4 タイトルの飾り：題字の線と星・薄い星空・ホバーの帯
- HUD-5 レビュー指摘の修正（今回）：
  - H1 文字の style を「前と違うときだけ」設定（`src/ui/text-style.ts`）。開発版で1フレームあたりの texImage2D が、何もしていないとき 12 → 0、画面を開いたとき 42 → 0（インベントリなどの画面 `EquipmentPanel` にも同じ書き方があったので同じ関数に直した）
  - M1 CD中は理由に関わらず覆いと残り秒（`onCooldown`）。M2 照準の世界座標を揺れを含まない式に（`InputSystem.pointerWorld`）。M3 被弾の演出は「回数が増え、かつHPが減った」ときだけ
  - T1 `CooldownTracker.endFrame` が観測されなかった技を忘れる。T2 `lowHp` のHP0の理由をコメントに
  - L1〜L7・L10〜L13（技の枠を34→38px、薬瓶の数字の位置、下の帯の刻み、CD秒の丸め、HPは切り上げ、毎フレームの割り当て、Lv UP の2つ同時、ゲージの個数の区切り、文章の ja.json 化と重複の解消、タイトルのホバー）

## 暫定で決めたこと
| ID | 判断 | 理由 | 戻し方 |
|---|---|---|---|
| D-HUD-1 | 詳しい情報は試験用の場でも初期は出さない | 画面が散らかる | ArenaScene の `showDebug` に `\|\| this.sim.region === undefined` |
| D-HUD-2 | 技の枠の状態に "empty"（空き）を足した | 枠に技が無いときの見た目が要る | `HudSkillState` から外す |
| D-HUD-3 | HPが少ないとみなすのは30%未満（`LOW_HP_RATIO`） | 仕様に数値が無い | 定数を変える |
| D-HUD-4 | 被弾の揺れ `shake(100, 0.003)`、会心・崩しの揺れ `shake(80, 0.003)`（元は 0.004） | 約2ピクセル。強すぎると読みにくい | ArenaScene の数値 |
| D-HUD-5 | CDの総時間が分からないときは覆いを全体にかけ、残り秒だけ出す | 総時間は表示の側で覚えているだけ | — |
| D-HUD-6 | MP不足・ゲージ不足・対象なしは枠の色で区別（文字は出さない） | 枠が狭い | `SLOT_TINT`・`SLOT_BORDER` |
| D-HUD-7 | 技の枠の幅を34→38px（名前は4文字まで、字は8pxのまま） | 4文字=32pxが枠の線にかかった。3文字に切ると読めない・字を小さくすると潰れる | `HUD_LAYOUT.skills.box` |
| D-HUD-8 | CDの残り秒は切り上げ（10秒未満は0.1秒、以上は整数）。効果の札も切り上げ | 10秒前後で桁が行き来しない | `secondsText` |
| D-HUD-9 | HPなどの数値は現在値を切り上げ（生きている間は0と出ない）。ゲージは切り捨て | ボスのHPの表示と同じ／溜まった分だけ見せる | `wholeText` の mode |
| D-HUD-10 | ゲージの区切り（pips）は、段階が無く最大が2〜10の整数のとき（盗賊5・騎士10・召喚士10）。魔法使い（最大3・段階あり）は対象外 | 条件を単純に | `PIPS_MAX_COUNT`・`gaugeVital` |
| D-HUD-11 | 枠から外している間に観測されなかった技の総時間は忘れる。入れ直した時点の残りが総時間になる（同じ技を別の枠へ動かしたときも、覆いが一度全高から始まる） | 古い総時間を出さないため | `CooldownTracker.endFrame` |
| D-HUD-12 | カメラの揺れで HUD も揺れる件は、直さない | 揺れは画面全体の行列に足される。HUD だけ止めるには2つ目のカメラ（世界の物を全て ignore）が要り、物の作成箇所が多い | 将来：HUD 用カメラ＋レイヤー |

## 仕様の疑問
- 技以外から付く効果の名前（`hud.buff.*`）は仮の名前（特に `uniform-light` の「軽装の身のこなし」）
- 魔法使いの位相（最大3）も、個数で数えるゲージとして区切りを出すか（今は段階が1つあるので出していない）

## テストプレイで確かめてほしいこと
1. HUD の読みやすさ（技の名前・CDの秒・薬瓶の数）
2. 揺れの強さ（被弾・会心）。盾で防いだ・魔障で吸収したときに赤い縁が出ないか
3. Lv UP の見え方（キャラLvとジョブLvが同時でも重ならないか）
4. 技の枠の色の区別（MP不足・ゲージ不足・対象なし）と、CD中の対象なしで覆いが出るか
5. 画面（I・C など）を開いたとき、下の帯の棒が読めるか
6. タイトルで行を選んだ直後、ポインターを動かさなくてもホバーの帯が出るか
