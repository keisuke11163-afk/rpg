- HUD-8／SFX-2 レビュー指摘の修正（`packages/core`・`arena-simulation.ts` は変えていない）：
  - **ボスの間で横に揺れない**：地図（512×448px）が画面の幅（640px）より狭く、`clampX` の最小と最大が同じになり横のずれが0だった。さらに Phaser は描画の前（`Camera.preRender`）に `useBounds` が true だと scrollX を `clampX` で切り詰めるので、bounds の外へ足したずれは画面に出ない。そこで `camera.useBounds = false`（切り詰めは `followCamera` が自分で行う。`clampX`・`clampY` は `setBounds` の値を使うので残す）にし、動ける幅が無い向きは `shakeOffsetWithinBounds` がずれをそのまま返す。`setViewOffset` には実際に足したずれを渡す（照準に漏れない）。`shakeWithinBounds` の仕様変更に合わせて「min=max なら base」のテストを「base + offset」に直し、min=max で base が範囲外・offset が NaN/Infinity・小数の base のテストを足した
  - **`SfxEventTracker`** が受け取った Map をそのまま覚えていた（同じ Map の中身が増えると前後が同じに見える）。トラッカーが自分の `Map<string, number>` を持ち、増えた技を見つけながらその場で書き換える。`ArenaScene` は `sim.uses` をそのまま渡す（毎フレームの `new Map` をやめた）。失敗中だったテストが通る
  - **被弾の揺れ**を前の版に近づけた（D-HUD-4）：被弾 2px・110ms、会心・崩し 1.5px・90ms。整数への丸めを確かめたところ、四捨五入では1.5pxの揺れの約3/4のフレームが0になったので、0 から離れる向きに丸める `roundShake` にした
  - **毎フレームの割り当て**：装備は部位ごとの uid の配列（使い回し）をトラッカーが自分の写しと比べる（文字列を作らない。`SfxObservation.equipment` は `readonly (string | undefined)[]` に）。`cameraBase`・`cameraShake`・`setViewOffset` の `{x,y}` は使い回す
  - **`sfx.ts`**：`onended` でフィルターも `disconnect`。コンプレッサーの knee を6dBと明示。周波数帯のコメントを実際の定義に合わせた
  - **連続ヒットの音**（D-SFX-7）・**通常攻撃の振る音**（D-SFX-8）：どちらも耳での確認はまだ（仮の判断）
  - **拾った音の検出漏れ**（D-SFX-9）：「持ち物が増え、画面を開いていない」に変えた
  - e2e：音量の行を、行の文言（「音量」）で探す（`settingsRowBoxes` に `label` を足した）。ボスの間で揺れを起こし、横にもずれが出る・カメラの左上が横に動く・照準が変わらないことを確かめる項目を足した（開発用の `aim()` に描画のカメラの左上 `viewX/Y` を足した）
  - **見え方の変化**：地域に入った直後のカメラが最初のフレームからプレイヤーに合う（`startFollow` の頃は、左上から約0.5秒かけて寄ってきた）。ボスの間（幅が画面より狭い）では、揺れで地図の外の空白が少し動いて見える

## 仕様の疑問
- 効果音：通常攻撃の近接は技の音を外した（D-SFX-8）。物足りなければ戻す。ヒットの間隔70ms（D-SFX-7）も耳で確かめていない
- 効果音：転職（G）で装備が替わると ui が鳴る。店で買う・装備を外すときは画面を開いているので pickup は鳴らない
- 敵の攻撃の予兆（溜め）・ボスの段階の切り替えの音は作っていない（今回の一覧に無い）
- 技以外から付く効果の名前（`hud.buff.*`）は仮の名前（特に `uniform-light` の「軽装の身のこなし」）
- 魔法使いの位相（最大3）も、個数で数えるゲージとして区切りを出すか（今は段階が1つあるので出していない）

## テストプレイで確かめてほしいこと
1. HUD の読みやすさ（技の名前・CDの秒・薬瓶の数）
2. 揺れの強さ（被弾・会心）。盾で防いだ・魔障で吸収したときに赤い縁が出ないか
3. Lv UP の見え方（キャラLvとジョブLvが同時でも重ならないか）
4. 技の枠の色の区別（MP不足・ゲージ不足・対象なし）と、CD中の対象なしで覆いが出るか
5. 画面（I・C など）を開いたとき、下の帯の棒が読めるか
6. タイトルで行を選んだ直後、ポインターを動かさなくてもホバーの帯が出るか
7. 揺れ（HUD-6・HUD-8）：被弾（2px）・会心（1.5px）で画面が揺れ（弱すぎないか。前の版と比べて）、HUD（棒・技の枠・地図）は揺れないか。地図の端に立ったときも揺れが見えるか。揺れている最中に照準がぶれないか
8. 撃破の演出（HUD-7）：散る図形・白い光・輪が、うるさすぎないか・足りないか（特に雑魚の群れを範囲攻撃でまとめて倒したとき）
9. 効果音（SFX-1）：うるさくないか（音量80%で）。耳に痛い音（高すぎる・長すぎる）が無いか。範囲攻撃で多くの敵に当てたとき・旋風（連続のヒット。間隔を70msにした）で機関銃のようにならないか・通常攻撃の空振りが無音で物足りなくないか・・単調すぎないか。足りない音（敵の攻撃の予兆・ボスの段階・メニューを閉じる など）
10. 効果音：最初のキー・クリックの前の音が鳴らないのは自動再生の制限のため（正しい）。タブを切り替えて戻ったときに鳴るか
11. 設定の音量を変えたときの確認の音で、音量が分かるか。音量0で何も鳴らないか
