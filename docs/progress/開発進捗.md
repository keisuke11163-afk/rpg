## 再開の手順（セッションが終わった場合）

1. `git fetch origin` で全てのブランチを取得する
2. この記録の「現在の状態」で、最後に完了した単位と次の単位を確かめる
3. 次の単位のブランチを、最後に完了した単位のブランチから作る（前のPRが develop に入っていれば develop から）。**作業を始める前に `git branch --show-current` で、新しいブランチにいることを確かめる**（U-10 で、前の単位のブランチに一度コミットしてしまった。押し上げる前に気づき、新しいブランチに移した）
4. `pnpm install` → `pnpm check` で、環境が正しく動くことを確かめてから着手する
