| 3. 撃破の後のダメージ | 的の残りHPを持ち、実際にHPを減らした分だけを打撃・持続ダメージ・技ごとのダメージに集計する。残りHPが0になったヒットで撃破とし、そのヒットの状態異常・崩しは与えず、残りのヒットは計算しない。ヒットで倒した時間刻みでは持続ダメージ・的の攻撃を進めない。持続ダメージも残りHPまでしか集計しない。超えた分は `overkillDamage`（参考の値）に分け、合計・DPSには含めない。撃破の時間＝倒した時間刻みの終わり（`(step+1)×dt`。ヒットと持続ダメージで同じ）＝戦闘の終わりで、DPS・受けたダメージの毎秒の分母に使う。倒さなければ、最後の時間刻みの終わり（従来どおり） |
| 4. 時間の検証 | `simulate()` の入口で `validateSeconds()`（export）により、0以下・NaN・±Infinity を RangeError にする（0・既定値に置き換えない）。時間刻みの回数が安全な整数を超える値も拒否する。CLI の `--seconds` は `tools/sim/src/options.ts` の `parseSeconds()` で読み、10進の数・±Infinity 以外（空・`abc`・`0x10`・`10s` など）は NaN として拒否し、入力の文字列を示すメッセージで終了コード1にする。`--seconds` の値がない場合も既定値にせず拒否する。省略したときだけ60秒 |
| 変えていないもの | 生き残る的での結果（標準の人形での3つのビルドのDPSは修正前と同じ：12.5・17.3・15.6）、ダメージ・状態異常・防御の計算（core の関数のまま）、既存のテスト（変更なし） |
| テスト | `tools/sim/test/sim-review.test.ts` に19件を追加（修正1：4件、修正2：5件、修正3：5件、修正4：5件）。修正前のシミュレーターでは、このうち15件が失敗することを確かめた。全体271件が合格 |
