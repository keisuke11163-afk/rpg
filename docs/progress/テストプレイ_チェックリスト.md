# テストプレイのチェックリスト（MVP）

> 目的：自動のテストでは分からない「手触り」と、今回の暫定決定（D-FIN-2〜7）が正しいかを、人が遊んで確かめる。
> 作成：2026-11-12。決定の詳しい内容は [開発進捗](開発進捗.md) の「最後の暫定決定」。
> 結果は、各項目の「問題のサイン」に当てはまったかどうかと、気づいたことを一言で書いてもらえれば十分です。

## 0. 始め方

```sh
pnpm install
pnpm dev        # http://localhost:5173/ をブラウザで開く
```

- **通常のプレイ**：タイトルで空きのスロットを選び、最初から始める（星見の村から。Lv1）
- **短く確かめたいとき**：タイトルの「開発用：試験用の初期の状態（Lv15）で始める」（開発版のビルドだけに出る）
- 操作（補助仕様書1.1）：移動 WASD・照準 マウス・技 左クリック／右クリック／1〜4・回避 スペース・薬瓶 Q／E・拾う F・インベントリ I・キャラクター C・星辰盤 T・職紋盤 J・地図 M・メニュー Esc。割り当ては設定で変えられる

所要時間の目安：通しで2〜3時間（A1 → 中ボス → 母樹 → 深淵の母樹まで）。短縮版は ★ の項目だけ（約45分）。

## 3. 深淵の母樹に、まったく違う3つ以上のビルドで勝てるか（完成の条件3。D-FIN-7）

ボットでは3つのビルドで勝てることを確かめた。人の操作で、次のうち3つ以上で勝てるかを見る。

| # | ビルド（`pnpm bench` の BENCH_BUILDS と同じ形） | 問題のサイン |
|---|---|---|
| ★3-1 | 盗賊・短剣（出血と毒）：千の小傷＋毒血同源＋千変 | 倒すのに2分半を超える／毒の雲で何度も倒れる |
| ★3-2 | 戦士・大斧＋重装＋重荷の誇り | 予兆を見て避けても被弾が多すぎる |
| ★3-3 | 戦士・徒手の極意（素手）＋樹皮の盾 | 1分以内に終わる（まだ強すぎる。D-FIN-5） |
| 3-4 | 盗賊・短剣の二刀流（双牙）＋影法師 | 二刀流が単に弱い（D-FIN-4） |
| 3-5 | 基準の戦士（大剣・ユニークなし） | ユニーク・天極なしでは勝てない |

撃破の秒数の目安：60〜120秒（標準のビルド）。撃破した秒数・倒れた回数をメモしてもらえると、調整に使えます。
