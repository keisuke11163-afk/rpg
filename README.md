# ステラシジル（仮題）

見下ろし型 2D ドット絵ファンタジー ARPG（ハック＆スラッシュ）。
装備収集・巨大なパッシブツリー・ジョブの3システムの相互作用で、ビルドを発見する楽しさを中心にしたゲーム。

> 現在の状態：**仕様の確定段階**。ゲームのコードはまだない。
